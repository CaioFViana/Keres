# Keres - Story Organizer Monorepo

This is the monorepo for the Keres project, an offline-first story organizer.

## Structure

- `apps/api`: Elysia (Bun) backend API.
- `apps/client`: React Native/Expo frontend.
- `packages/shared`: Shared types, utilities, and Zod contracts.
- `packages/db`: Drizzle ORM schema and migrations.
- `packages/config`: Common configurations.
