### 1.2: Themis: 
_"Balance, order, equilibrium, justice. To make it fair, to make sure everyone is heared, to make sure no one is forgotten."_

The release to give See also and Comments. To make sure every entity can be heared, to make sure even other readers are heared, even if not directly linked to others. But the most important feature was mainly the setup for next release with testing framework decided.

### 1.3: Ouroboros: 
_"The serpent eats itself, spinning for infinity milenias, making sure its always respected and eternal. Its their choice. Its the cycle."_

The main theme was code wise. Testing framework. Any professional code uses it, and I deeply regret not using it earlier. Besides that, many bug fixes were found from it, even allowing restoring old stories. Ouroboros means its a cycle. The testing framework cycle of checking one by one, again and again.

What else got a cycle themed release? Story analysis followed the theme adding checks and effects and the algorithm to check them for inaccessible ones. All fit together.

Will say, favorite feature was the help pages.
